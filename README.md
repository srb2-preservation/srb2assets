## SRB2 Assets

This repository contains the main game assets for srb2-preservation's projects. To get the assets for any of the projects, checkout the branch corresponding to the project you need the assets for. For example, the `legacy` branch contains assets for SRB2 Legacy (2.1), while the `retro` branch contains assets for SRB2 Retro (2.0). Some branches may contain additional asset files from those used by the original version, these are optional and NOT required to launch the game.
